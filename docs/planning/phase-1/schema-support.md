# Supporting physical schema proposal

Status: draft for P1.5, not approved; no migrations. These tables accompany the 616 typed compatibility tables in schema-physical.md. They are a preservation design, not a finished unified operational model. All tables use InnoDB; identifiers are BIGINT UNSIGNED; all columns are NOT NULL unless `NULL` is stated. Text identifier comparisons use utf8mb4_bin; opaque keys use binary storage. All FKs use RESTRICT on delete/update. No cascading destruction of historical evidence.

| Table | Complete proposed columns | Constraints / indexes and purpose |
|---|---|---|
| cities | id BIGINT UNSIGNED; code VARCHAR(16); name_en VARCHAR(100); name_ar VARCHAR(100) | PK id; UNIQUE code; exactly five configured city records |
| sources | id BIGINT UNSIGNED; city_id BIGINT UNSIGNED; code VARCHAR(64) | PK id; FK city_id → cities.id; UNIQUE code; UNIQUE(id,city_id) for later city-consistency contracts |
| source_tables | id BIGINT UNSIGNED; name VARBINARY(64) | PK id; UNIQUE name; all 127 original table names |
| snapshots | id BIGINT UNSIGNED; source_id BIGINT UNSIGNED; archive_sha256 BINARY(32); sql_sha256 BINARY(32); manifest_locator VARBINARY(1024); captured_at DATETIME(6) NULL | PK id; FK source_id → sources.id; UNIQUE(source_id,sql_sha256); UNIQUE(source_id,id). Unknown capture time stays NULL; filenames are not a certified capture timestamp |
| migration_runs | id BIGINT UNSIGNED; snapshot_id BIGINT UNSIGNED; tool_version VARCHAR(100); started_at DATETIME(6); completed_at DATETIME(6) NULL; status VARCHAR(32); evidence_locator VARBINARY(1024) NULL | PK id; FK snapshot_id → snapshots.id; index(snapshot_id,status). UTC audit timestamps; allowed status validation required |
| source_records | id BIGINT UNSIGNED; source_id BIGINT UNSIGNED; table_id BIGINT UNSIGNED; snapshot_id BIGINT UNSIGNED; source_key LONGBLOB; key_sha256 BINARY(32); key_kind VARCHAR(16); import_run_id BIGINT UNSIGNED; resolution_status VARCHAR(32) | PK id; UNIQUE(source_id,table_id,snapshot_id,key_sha256); UNIQUE(source_id,table_id,id); FK(source_id,snapshot_id) → snapshots(source_id,id); FK table_id → source_tables.id; FK import_run_id → migration_runs.id. Importer must verify run belongs to snapshot; digest collision fails closed after full-byte comparison. key_kind = primary/ordinal |
| relationship_contracts | id BIGINT UNSIGNED; source_id BIGINT UNSIGNED; child_table_id BIGINT UNSIGNED; parent_table_id BIGINT UNSIGNED; name VARBINARY(128); child_columns_json JSON; parent_columns_json JSON; evidence_locator VARBINARY(1024); contract_kind VARCHAR(32) | PK id; FKs source_id → sources, table IDs → source_tables; UNIQUE(source_id,child_table_id,name); UNIQUE(id,source_id,child_table_id,parent_table_id). Arrays preserve column order; contract_kind declared/application/typed-discriminator |
| record_relationships | id BIGINT UNSIGNED; contract_id BIGINT UNSIGNED; source_id BIGINT UNSIGNED; child_table_id BIGINT UNSIGNED; child_record_id BIGINT UNSIGNED; parent_table_id BIGINT UNSIGNED; parent_record_id BIGINT UNSIGNED NULL; status VARCHAR(32); evidence_locator VARBINARY(1024) NULL | PK id; UNIQUE(contract_id,child_record_id); FK(contract_id,source_id,child_table_id,parent_table_id) → relationship_contracts(id,source_id,child_table_id,parent_table_id); FK(source_id,child_table_id,child_record_id) → source_records(source_id,table_id,id); FK(source_id,parent_table_id,parent_record_id) → source_records(source_id,table_id,id); indexes on both FK tuples. CHECK parent_record_id IS NOT NULL iff status=resolved. Raw values remain in the child's typed table, not overwritten |
| migration_exceptions | id BIGINT UNSIGNED; run_id BIGINT UNSIGNED; record_id BIGINT UNSIGNED NULL; relationship_id BIGINT UNSIGNED NULL; category VARCHAR(64); state VARCHAR(32); evidence_locator VARBINARY(1024); decision_text TEXT NULL; reviewed_by VARCHAR(128) NULL; reviewed_at DATETIME(6) NULL | PK id; FKs run_id → migration_runs, record_id → source_records, relationship_id → record_relationships; index(run_id,state,category); review identity is an explicit audit reference, not a guessed imported user |
| project_number_sequences | source_id BIGINT UNSIGNED; next_number BIGINT UNSIGNED | PK/FK source_id → sources.id; lock row during allocation; no gap reuse |

Every composite FK receives an index in listed column order where no existing PK/UNIQUE prefix covers it. `source_records` maps each record to the typed table via source/table IDs; the typed-table composite FK enforces this. Require one typed row per registry row before a batch is complete. Validate registry-to-typed cardinality independently; the registry alone cannot enforce the existence of a child typed row.

Conditional relationship contracts are separate for each verified discriminator. An unresolved overloaded value gets an exception, not several guessed parent links. Parent snapshots must match the child's snapshot; this is a mandatory importer/reconciler check in this draft (not currently enforced by the listed ledger FKs). A schema review must decide whether to promote snapshot IDs into the ledger's composite FKs before acceptance. Restored source anomalies remain in raw columns regardless of relationship status.

Attachment manifest fields are specified in preservation-spec.md. Its final physical catalog, login principals/grants, audit events and unified operational tables remain open design work; this draft does not represent them as completed tables. Existing source users and BLOBs are fully mapped in the typed layer. Historical username text never becomes a compulsory FK to a web login.

New web business writes and replacement snapshot reconciliation need an accepted operational model, including a separate business identity from immutable snapshot occurrences. This schema may be approved as a preservation layer independently; it must not be mistaken for approval of the entire P1.2 target operational schema.
