# Micro Projects Web

Laravel + Livewire conversion of the Micro Projects desktop workflows for Aleppo, Damascus, Homs, Latakia and AlWadi.

This repository currently contains planning and static discovery evidence. No Laravel application has been scaffolded, no source database restored, and no production migration performed.

- [Execution plan](docs/planning/team-execution-plan.md)
- [Accepted Phase 0 scope](docs/planning/p0-4-scope-contract.md)
- [Phase 0 review](docs/planning/p0-coordinator-review.md)
- [Delivery board](docs/delivery/task-board.md)

The `p1-2-*` artifacts are pre-existing, incomplete schema drafts. Their referenced `p1-2-target-physical-schema.md` was not present in the supplied planning folder. They do not establish Phase 1 completion or schema approval.

Discovery scripts depend on local read-only desktop/archive paths documented in their source; the original datasets are intentionally not included. Counts are parsed snapshot counts, not restored integrity certification.

Use this checkout for future work. Commit and push each task/phase as instructed in [AGENTS.md](AGENTS.md).
